First, ensure that `mpimarkers` is [installed](/mpimarkers/getting-started/installation/).

## Basic usage

After installation, you can run the application with:

```bash
mpimarkers
```

which calls `mpimarkers.main.main` and prints a greeting.

## Use the package from Python

```python
from mpimarkers.main import main

main()
```

See the [API reference](/mpimarkers/api/mpimarkers/) for every module and function.
