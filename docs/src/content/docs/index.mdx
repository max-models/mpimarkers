## What it does

<CardGrid>
	<Card title="Particle store" icon="open-book">
		Component-major positions, velocities, weights, alive flags and int64 ids on NumPy or CuPy, with growth, compaction, sorting and checkpoints.
	</Card>
	<Card title="Unique ids" icon="setting">
		An id allocator with a rank stride gives every marker a globally unique int64 id that survives migration.
	</Card>
	<Card title="Migration" icon="rocket">
		Only the markers that left a rank are sent to their owner, with ids kept exact above 2^53. Serial runs make no MPI call.
	</Card>
	<Card title="Your decomposition" icon="document">
		A small protocol says which rank owns a position; a box decomposition is included as a reference.
	</Card>
</CardGrid>
